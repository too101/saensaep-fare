# ค่าโดยสารเรือคลองแสนแสบ

เว็บแอปเช็กค่าโดยสารเรือคลองแสนแสบ ครบทั้ง 27 ท่า แตะเลือกท่าต้นทาง–ปลายทางบนแผนผัง เห็นราคาทันที ไม่ต้องเปิดตารางหรือถามใคร

**🔗 ใช้งานได้ที่:** https://too101.github.io/saensaep-fare/

![preview](./og-image.png)

---

## ฟีเจอร์

- แตะเลือกท่าต้นทาง–ปลายทางบนแผนผัง 2 คอลัมน์ เห็นราคาทันที พร้อมราคากำกับท้ายชื่อทุกท่า
- รองรับ **ภาษาไทย/อังกฤษ** สลับได้ทั้งหน้า (ปุ่มมุมขวาบน เปิดเว็บครั้งแรกเป็นไทยเสมอ)
- ชื่อท่าเรือทั้ง 27 ท่าอ้างอิงชื่อทางการจากกรมเจ้าท่า (ไทย/อังกฤษ)
- ปรับ **ค่าโดยสารเริ่มต้นได้เอง** เผื่ออัตราค่าโดยสารปรับขึ้นในอนาคต ราคาทุกระยะขยับตามอัตโนมัติ (ส่วนต่างคงที่ +2 บาทต่อขั้น)
- ออกแบบให้พอดีจอเดียวบนมือถือ ไม่ต้องเลื่อน พร้อมกลไกสำรองสลับเป็นโหมดเลื่อนอัตโนมัติเมื่อเนื้อหาไม่พอดีจริง ๆ (เช่น เบราว์เซอร์ในแอป LINE ที่ขยายฟอนต์เอง)
- **เพิ่มไปยังหน้าจอหลักได้** ทั้ง Android และ iPhone (PWA) เปิดใช้งานได้เหมือนแอปจริง
- แจ้งเตือนอัตโนมัติเมื่อมีเวอร์ชันใหม่กว่าที่กำลังใช้อยู่ (เช็กทุก 6 ชั่วโมง)
- สถิติผู้เข้าชมแบบไม่ใช้คุกกี้ ไม่เก็บข้อมูลส่วนตัว ([GoatCounter](https://www.goatcounter.com/))

## ที่มาของข้อมูล

ตารางค่าโดยสารถอดจากป้ายตารางราคาของผู้ให้บริการ และตรวจทานเทียบกับ[แดชบอร์ดของกรมเจ้าท่า](https://datastudio.google.com/reporting/877d0db2-0cd5-4c80-ae46-d53e2e37ad0a/page/BiVIF)

> ⚠️ อัตราค่าโดยสารอาจเปลี่ยนแปลงได้ โปรดตรวจสอบป้ายประกาศที่ท่าเรืออีกครั้งก่อนเดินทาง

## เทคโนโลยีที่ใช้

ไฟล์เดียวจบ — ไม่มีขั้นตอน build ไม่ต้องติดตั้ง dependency ใด ๆ

- HTML / CSS / JavaScript ล้วน (vanilla)
- ฟอนต์ [Google Sans](https://fonts.google.com/specimen/Google+Sans) ผ่าน Google Fonts
- [GoatCounter](https://www.goatcounter.com/) สำหรับสถิติผู้เข้าชม
- Web App Manifest + Service Worker (แบบไม่แคชอะไรเลย) สำหรับรองรับการติดตั้งเป็นแอป

## โครงสร้างไฟล์

```
├── index.html              เว็บแอปหลัก (ทุกอย่างอยู่ในไฟล์นี้)
├── manifest.json            ตั้งค่าชื่อ/ไอคอนตอนเพิ่มไปหน้าจอหลัก
├── sw.js                     service worker (ไม่แคชอะไร มีไว้ให้ผ่านเกณฑ์ติดตั้งแอปของเบราว์เซอร์)
├── icon-192.png              ไอคอนแอป (Android)
├── icon-512.png              ไอคอนแอป (Android)
├── icon-maskable-512.png     ไอคอนแอปแบบเผื่อขอบ (Android adaptive icon)
├── apple-touch-icon.png      ไอคอนแอป (iOS)
├── favicon-32.png            ไอคอนแท็บเบราว์เซอร์
├── og-image.png              ภาพตัวอย่างตอนแชร์ลิงก์ (Open Graph)
├── boat-schedule.png         อินโฟกราฟิกตารางเวลาเดินเรือ
└── CHANGELOG.md              บันทึกการเปลี่ยนแปลงทุกเวอร์ชัน
```

## รันเองเครื่องตัวเอง

ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือจะรันเซิร์ฟเวอร์เล็ก ๆ เพื่อให้ฟีเจอร์ที่ต้องใช้ HTTP (เช่นการเช็กเวอร์ชันใหม่, service worker) ทำงานได้ครบ:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```
